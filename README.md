# CloudGuard – AWS IAM Security Monitoring Dashboard

## Overview

CloudGuard is a cloud security monitoring dashboard designed to help organizations visualize IAM risks, compliance status, security alerts, and audit activities across AWS environments.

The platform provides an intuitive interface for monitoring user access, identifying high-risk accounts, tracking compliance metrics, and generating security reports.

---

## Problem Statement

Cloud permission sprawl is a major security challenge in modern cloud environments.

As employees join, leave, or change roles, permissions often accumulate without proper cleanup. Over-privileged accounts, inactive users, and missing security controls can increase the risk of unauthorized access and data breaches.

CloudGuard helps security teams identify and monitor these risks through a centralized dashboard.
